# Repository

- **`embedding/`** - Entity and relation embeddings generated by text-embedding-3-large.
- **`clustering/`** - Clustering algorithms and utilities for KG entities.

- **`graphloader.py`** - Loads and processes the medical knowledge graph.
- **`kg_raw.txt`** - Raw knowledge graph data (procedures, conditions, drugs). Download from https://github.com/pat-jj/KARE/blob/main/graph/kg_raw.txt
